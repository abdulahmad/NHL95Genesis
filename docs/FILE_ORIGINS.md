# Where the NHL 95 code came from

Each 95 source file, in ROM order, with the NHL94Genesis file each of its routines and tables came from. Generated by `tools/file_origins.py` from the full build listing; every label with its address, size and the evidence is in `function_origins.csv`.

A label is assigned by the first rule that applies:

1. **name**: a global label of that name in an NHL94Genesis file (the shared `rts` labels excepted).
2. **header**: the header says `95 only` (new in 95), or names the 94 file or 94 routine.
3. **fingerprint**: `tools/segmap95.json` matched the bytes to a 94 routine.
4. **name (93)**: a label only NHLPA93Genesis has.
5. **follows**: a table, shared `rts` or entry point with no evidence of its own takes the label before it.
6. **file**: the rest of a file that is new in 95 (season95, trade95, create95, awards95, schedule95) is new in 95.

Sizes run from a label to the next one, so the vectors ($0-$FF) and the header before CountryCode are not counted. Percentages are by bytes. "new in 95" means 94 has no routine like it.
